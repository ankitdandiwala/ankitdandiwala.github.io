# Ankitkumar Dandiwala — CV and selected projects

A responsive, text-led personal website built with HTML, CSS and vanilla JavaScript.

- No photographs, stock images, external illustrations, videos or third-party visual assets are included.
- The content is intentionally restrained and CV-oriented.
- Selected numerical results are shown within the relevant project descriptions and linked to the corresponding publications.

## Preview locally

1. Extract this folder.
2. Open `index.html` in a browser, or run `python3 -m http.server 8000` from this folder.
3. Visit `http://localhost:8000`.

## Before publishing

- Replace `YOUR_EMAIL_ADDRESS` with the email address you want public.
- Check the academic teaching entry and confirm the institution names and dates.
- Verify all CV details, publication titles and result wording against your final CV and papers.
- Add a portrait or project photographs only if you provide and approve those exact images.

No laptop needs to remain switched on when the site is hosted with GitHub Pages.
